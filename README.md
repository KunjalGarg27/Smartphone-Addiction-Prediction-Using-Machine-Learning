# Smartphone Addiction Prediction Using Machine Learning
A machine learning project focused on predicting smartphone addiction using behavioral and lifestyle-related data. The project compares the performance of multiple classification algorithms — Decision Tree, Random Forest, and Support Vector Machine (SVM) — to identify the most effective model for addiction prediction. The repository includes complete preprocessing pipelines, feature engineering, model training, hyperparameter tuning, evaluation metrics, and visualization workflows.

Project Objective

The primary goal of this project is to analyze smartphone usage behavior and predict whether a user is addicted or not using supervised machine learning techniques. The system uses features such as:

Daily screen time
Social media usage
Sleep hours
Gaming hours
Stress level
Weekend screen time
Notification frequency
Academic/work impact

The project also explores how preprocessing decisions and feature engineering influence model performance.

Machine Learning Models Implemented
1. Decision Tree (Entropy)
2. Random Forest
3. Support Vector Machine (SVM)

Each model was independently developed and optimized to compare:

Accuracy
Precision
Recall
F1-Score
Cross-validation performance
Interpretability
Generalization capability
